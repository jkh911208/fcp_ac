만드는 한국어 자동 자막.

클립을 사이드바 패널로 끌어다 놓으면, 이 Mac에서 음성을 전사해 한국어 자막을 원본 클립에 연결된 채로 타임라인 캡션 레인에 올려 줍니다. 무료, 오픈소스, 계정 없음.

최신 릴리스 확인 중…

불러오는 중입니다

다운로드

왜 만들었나

Final Cut Pro 12.3에도 자막 전사 기능이 있습니다. 미국 영어 전용이라는 점만 빼면요.

지금

한국어 음성을 FCP 내장 전사에 넣으면 영어 모델이 알아듣지 못한 소리를 로마자로 옮겨 놓습니다. 그래서 다른 앱에서 전사하고, SRT로 내보내고, 다시 임포트하고, 타이밍을 손보는 왕복 작업을 하게 됩니다.

FCPCaption에서는

FCP 사이드바의 패널 하나. 끌어다 놓고 진행률이 끝나면 그걸로 끝입니다 — 자막은 이미 타임라인 캡션 레인에, 클립에 연결된 채로 올라와 있습니다.

동작 방식

앱을 바꿔 탈 일 없는 네 단계.

  1. 클립을 패널로 드래그

    Final Cut Pro가 클립의 FCPXML을 넘겨줍니다 — 미디어 경로, 타임라인 위치, 프레임레이트.

  2. AVFoundation으로 오디오 추출

    원본 미디어에서 바로. ffmpeg도, 재인코딩 왕복도, 나중에 지워야 할 임시 파일도 없습니다.

  3. 이 Mac에서 전사 — 또는 본인 API 키로

    WhisperKit이 large-v3-turbo를 Neural Engine에서 돌립니다. 모델은 한 번만 내려받고, 그 뒤로는 아무것도 기기를 떠나지 않습니다. 로컬 연산을 아끼고 싶다면 본인 OpenRouter 키를 쓰면 됩니다.

  4. 한국어 자막 규칙으로 나눠 FCP에 되돌려쓰기

    한 줄 18자, 최대 두 줄, 1~6초. 침묵과 문장 부호에서 끊고 어절은 중간에서 자르지 않습니다. 모든 값은 설정에서 조정할 수 있습니다.

요구 사항

  • Apple silicon Mac (M 시리즈). 인텔은 범위 밖입니다 — 모델이 Neural Engine에서 돌아갑니다.
  • macOS 15 (Sequoia) 이상
  • Final Cut Pro 12.x
  • 클라우드 엔진을 쓸 때만: 본인 OpenRouter API 키

개인정보

  • 텔레메트리도, 애널리틱스도, 계정도 없습니다.
  • 로컬 모드에서는 모델 다운로드 한 번 외에 네트워크 요청을 하지 않습니다.
  • API 키는 macOS Keychain에만 저장되고 로그에는 남지 않습니다.
  • MIT 라이선스 — 전부 GitHub에서 읽을 수 있습니다.

진행 상황

공개된 채로, 마일스톤 하나씩.

단계산출물
M0 ✅전사 스파이크: 파일 → WhisperKit → .srt, 한국어 자막 규칙 테스트
M1Extension 껍데기: FCP 사이드바 패널, 드롭된 FCPXML 파싱
M2임포트 스파이크: 이미 열린 프로젝트의 클립에 캡션을 붙일 수 있는가
M3로컬 E2E: 드래그 → 전사 → 타임라인에 자막
M4OpenRouter 엔진, Keychain, 설정 화면
M5서명·공증 dmg, GitHub Actions 빌드

앱이 나오기 전에 먼저 써보기

전사 부분은 이미 커맨드라인 도구로 동작합니다. 아무 오디오·비디오 파일 옆에 .srt를 만들어 줍니다.

git clone git@github.com:jkh911208/fcp_ac.git
cd fcp_ac/FCPCaptionCore
swift run -c release fcpcaption-cli /path/to/clip.mov --language ko
